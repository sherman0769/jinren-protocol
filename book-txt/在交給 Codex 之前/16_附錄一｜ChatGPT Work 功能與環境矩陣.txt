附錄一｜ChatGPT Work 功能與環境矩陣

本附錄的產品資訊以 2026 年 7 月 19 日為查證基準。Work、Codex、Library、Browser、Sites、Skills、Plugins、Scheduled Tasks、方案與額度都可能持續更新。使用前應以帳號內實際可用功能與 OpenAI 最新官方文件為準。

方法型範本可以長期使用；平台、方案與數量型資訊則需定期重查。

2. 雲端與桌面的保存判斷

Cloud Work

- 適合跨裝置持續的研究、文件、分析與成果交付。

- 可使用支援的 Project context、Library、Apps 與 Cloud Browser。

- 雲端對話在支援裝置間同步。

- 不應假設具有任意登入、付款、永久套件或本機檔案權限。

Desktop Work

- 在明示授權下可使用本機檔案與應用程式。

- 可結合內建 Browser 與本機工作環境。

- 本機執行緒與本機結果未必自動同步到雲端。

- 重要成果應明確保存到正式專案位置。

Codex

- 適合進入 Repository、終端、測試、diff 與正式工程。

- 可透過桌面、CLI、IDE extension 或獨立 web 客戶端等路徑使用；它並不是一般 ChatGPT web／mobile 對話中的普通模式選項。[R02][R15]

- 應以 AGENTS.md、測試、版本控制與核准政策管理。

3. 「九核心、十五 GB」傳聞辨析

截至查證基準日，OpenAI 沒有在官方產品文件中承諾每位使用者固定獨享一台「九核心、十五 GB 記憶體」的永久虛擬機。

較準確的說法是：

部分使用者可能在特定 Work 執行工作階段觀察到類似資源數字，但這不足以證明固定、專屬、持久或對所有帳號一致的硬體規格。

任何實測只能支持「當時環境呈現了什麼」，不能直接推導：

- CPU 是實體、專屬或可長期滿載。

- 記憶體可全部使用且永不調整。

- 工作階段關閉後套件、程序與檔案永久保留。

- 所有方案、地區、任務與時間都相同。

- OpenAI 對規格提供服務保證。

本書因此不以硬體數字作為 Work 價值主張。

4. 官方資訊有落差時怎麼寫

若不同官方頁面出現不完全一致的說法：

1. 記錄每一頁的更新日期與查閱日期。

2. 區分「一般 ChatGPT web 模式」與「獨立 Codex web 客戶端」等不同語境。

3. 不把某一頁的方案或額度數字寫成永久承諾。

4. 在正文保留穩定分工，在附錄記錄版本差異。

5. 以使用者帳號內實際顯示與最新官方文件作最後判斷。
