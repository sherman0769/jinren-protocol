附錄六｜版本風險與更新紀錄

1. 高變動項目

以下內容應在公開出版、授課或更新教材前重新查證：

- Work 可用方案、地區與分批推出狀態。

- Web、mobile、desktop 的功能同步。

- GPT-5.6 各模式、max／ultra 與方案權限。

- Work 與 Codex 的使用量、credits 與計價。

- Library 容量、檔案格式與推出範圍。

- Scheduled Tasks 的活動數、頻率與 Project files 存取。

- Google Workspace、Excel、PowerPoint 的原生整合。

- Sites 的測試狀態、資料、登入、區域與部署限制。

- Skills、Plugins、Apps 的命名、權限與管理方式。

- Cloud Browser 的登入、下載、付款與 CAPTCHA 能力。

2. 查證順序

1. OpenAI 官方 Help Center。

2. OpenAI 官方產品發布與 Release Notes。

3. ChatGPT Learn／Codex 官方文件。

4. 帳號內實際功能與工作區管理設定。

5. 若官方資料互相衝突，保留日期與語境，不自行挑一個寫成永久事實。

4. 本書版本原則

- 正文以穩定工作方法為主。

- 產品能力只支持方法，不主導章節結構。

- 數字、方案、價格、額度與介面位置集中附錄。

- 新功能若沒有推翻核心論點，不任意重寫全書思想線。

- 原創模型與官方事實持續分開標示。

5. 本版已知待補

- 【待補作者案例】第一次實際使用 Work 完成長任務的全程紀錄。

- 【待補作者案例】Work 準備後交給 Codex，與直接交付的成果比較。

- 【待補作者案例】協會或企業流程中的真實核准點。

- 【待補作者案例】一次性提示詞沉澱為 Skill／範本的過程。

- 【待補截圖】Work、Browser、Library、Skills、Plugins、Sites 與 Codex 的介面；只放更新包或圖說附錄，避免正文因介面改版快速失效。

這些待補項目不影響本版方法成立，但會是未來再版、課程與演講最有價值的實證素材。
