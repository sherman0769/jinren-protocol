# 縮寫與容易混淆的詞

| 名稱 | 展開或語境 | 先記成 |
|---|---|---|
| FPS | Frames Per Second | 影片每秒安排幾張畫面 |
| GPU | Graphics Processing Unit | 擅長大量平行計算的處理器 |
| API | Application Programming Interface | 程式與功能溝通的介面 |
| SVG | Scalable Vector Graphics | 用幾何與文字描述圖形的格式 |
| TTS | Text-to-Speech | 文字變說話聲音 |
| PCM | Pulse-Code Modulation | 用數字記錄音訊取樣 |
| QA | Quality Assurance | 有步驟的品質檢查 |
| SFX | Sound Effects | 音效 |
| JSON | JavaScript Object Notation | 常見的結構化資料文字格式，不代表只能給 JavaScript 用 |

渲染不等於編碼，編碼不等於封裝，封裝不等於混音。畫面狀態相同不等於不同編碼器產出的 MP4 位元相同。進度不是速度，振幅不是完整的感知響度，字體文件不是字串，字串長度不總是人眼看到的字數。

書中中文譯名固定，但允許括號補其他地區常見譯法，讓讀者查文件時不以為是兩套技術。不要為追求一詞一譯而寫錯技術。
