# 交接包地圖

根目錄 `START_HERE.html` 是離線閱讀入口，`AGENTS.md` 是 Codex 專案規約。所有書稿與設定均為 UTF-8。

| 資料夾 | 內容 | 狀態 |
|---|---|---|
| CONTEXT | 本書定位、作者意圖、讀者痛點與既有專案整合規則 | 已整理 |
| OUTLINE | 六部二十四章、相依順序與逐章寫作任務 | 任務卡，不是正文 |
| GLOSSARY | 109 張白話中英術語卡、縮寫與混淆表 | 待正文逐次對照使用 |
| STYLE_GUIDE | 文風、圖解、數學、程式與可讀性規範 | 寫作時遵守 |
| SAMPLE_CHAPTER | 第四章完整校準樣章 | 未經作者確認，非正式完稿 |
| READING | 可直接用瀏覽器閱讀的目錄、術語與樣章 | 離線 HTML |
| examples | 六張可重建圖解、八秒影片、最小程式 | 本次可執行例子，不是原案原始碼 |
| tests | 最小原理的單元測試 | 執行結果見 qa |
| RESEARCH | 一手來源入口與逐項查核規則 | 讀取失敗的來源不能當證據 |
| CASE_STUDY | 原案報告、媒體中繼資料、四張實際截圖 | 未附原案完整原始碼或長片 |
| CODEX_INSTRUCTIONS | 主指令、逐章寫作、雙重審查、續寫與總編輯 | 可直接交接 |
| MANUSCRIPT | 留給 Codex 的正式書稿輸出位置 | 本次尚未撰寫全書 |
| scripts | 結構驗證與書稿檢查提示器 | 不以機械檢查冒充人類讀者驗收 |
| qa | 本次實際測試與限制 | 與原案驗收分開記錄 |

`book.json` 保存書的設定；`work.json` 保存真實進度；`MANIFEST.json` 列出交接檔案的位元組數與雜湊。修改交接檔案後，原始雜湊不再相同是預期結果；一般寫作請執行不含 `--verify-manifest` 的結構驗證。
