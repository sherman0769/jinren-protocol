# 成片截圖觀察任務

四張圖片來自本次實際讀取的配樂字幕版。記錄的是按指定秒點截取並縮至 960 像素寬的結果，不是對原算法的鑒定。圖注請使用「可見」「此畫面可用來討論」而非沒有依據的「原始碼調用了」。

| 取樣時間 | 圖片 | 寫作者要做的事 |
|---|---|---|
| 02:00 | `evidence/case_t120.jpg` | 觀察元素、層級與標籤，提出一個資料或構圖問題 |
| 05:00 | `evidence/case_t300.jpg` | 觀察形狀與空間關係，選擇可獨立重建的最小機制 |
| 09:00 | `evidence/case_t540.jpg` | 分開截圖可見事實與運動推論，不能由單幀判斷速度曲線 |
| 11:00 | `evidence/case_t660.jpg` | 觀察排版與敘事角色，再決定適合放哪一技術章 |

需驗證運動時重新取多個相鄰時點或觀看原片；需驗證實現時查原始碼。不要把原對話中對另一支參考片的 300／540／660 秒算法猜測套到這些截圖上。
