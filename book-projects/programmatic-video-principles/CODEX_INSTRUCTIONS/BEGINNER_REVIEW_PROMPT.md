# 初學者審查指令

模擬一個會基本算術、用過 AI，但沒學過圖學英文的成人讀者。不要假裝是李詩民本人已讀過或認可。逐段尋找第一個讀不下去的位置。

逐條輸出：原句→未知概念或跳步→讀者會問的話→可直接替換的繁體中文解釋。特別檢查是否用 Interpolation 解釋 Easing、用 Glyph 解釋 Mask 等循環術語，以及圖里的詞是否比正文更早出現。

用全中文回答本章開頭問題，再預測改一個參數的結果，最後找出故意設置的錯誤。回答需要靠背名詞而不是理解時，判為需修改。檢查比喻後是否給出精確定義與適用邊界；太簡單而失真也應退回。

輸出 qa/reviews/CHxx_beginner.md。它是模型視角審查，不是人類讀者測驗；正式出版前仍應請真實讀者試讀。
