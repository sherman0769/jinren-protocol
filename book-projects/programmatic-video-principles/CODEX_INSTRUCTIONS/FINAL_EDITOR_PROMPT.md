# 全書總編輯驗收

逐章核對任務卡與實際書稿，不以文件存在代替內容完成。檢查從一個白點到最終作品的知識遞進、術語先後、中文一致性、例子命名、參數與圖是否同步、重復章節、缺少的因果環節及引用完整性。

建立覆蓋矩陣：每章的問題、核心原理、術語卡、圖、執行例子、反例、練習答案、來源、模型審查、人類試讀狀態。缺一項就記錄，不把教學任務清單算作成稿。

全書完成條件：24 章正文及前言形成完整可閱讀稿；所有必需程式碼在記載環境可重建；展示結果來自實際程式碼；重要技術事實有正確來源；沒有未標明的佔位與案例偽造；核心英文首次解釋符合原則；媒體輸出及閱讀版已按其實際完成狀態驗證。人類試讀未發生時明說，而不是冒充出版終審。
