# 技術審查指令

你現在進行技術審查，不負責贊美作者。逐個檢查公式、單位、邊界、坐標約定、隨機性、狀態模擬、字形、聲音時間碼、渲染／編碼／封裝區別及源自原案的主張。

引用具體原句或函數；復算數值；執行例子；核對實際輸出而不是只看程式碼。對每個問題寫嚴重性、原因、反例、修改建議及復測方法。沒有原原始碼不能認定原片使用某個具體算法；截圖只能支持可見事實。

特別查：N 與 N−1、半開區間、起點和終點停留、相同幀重復畫一致、亂序取幀一致、seed 的條件、除以零、非有限數值、字體缺字、字幕超窗、聲音長度、碼率與容器混淆。不要因為測試全綠就聲稱美術或聽感通過。

輸出 qa/reviews/CHxx_technical.md。記錄真實命令、環境、結果和未驗證項；同一模型審稿請明確標「模型技術審查」，不可署名成虛構工程師。
