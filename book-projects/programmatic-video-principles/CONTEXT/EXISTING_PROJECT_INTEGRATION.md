# 與既有寫書母專案的整合

本次已確定的是書籍題目與學習目標，**沒有確認使用者本機寫書母專案的實際路徑或儲存庫**。不要因其他對話出現 `D:\MyGitHub` 就假定應寫入其中某個目錄。本包不建立雲端專案、不呼叫既有儲存庫、不更改全域 Codex 設定。

Codex 接手時若使用者已在其既有寫書專案中開啟本包，先讀該專案 README、規約、索引、範本與版本狀態。把本書加入獨立書籍子資料夾，保留既有構建流程；把合併結果寫入整合紀錄，不覆蓋母專案的 AGENTS.md。

若無現成母專案，就在本資料夾繼續，無需為了未知路徑停下來。將來再按母專案明確規約整合。不要把其他書的格式、篇幅、發佈平台視為本書已確認需求。
