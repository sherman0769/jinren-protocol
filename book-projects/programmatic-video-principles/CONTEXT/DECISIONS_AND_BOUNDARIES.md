# 決策脈絡與專案邊界

本頁是依本次對話整理的意旨摘要，不冒充逐字會議紀錄。沒有把其他影片或語音系統的偏好移植到本書。

## 對話如何走到這本書

最初先分析一支約 12 分 30 秒的程式驅動參考影片，討論粒子、文字、網路、曲線與渲染。其後規劃並產出原創作品《當世界開始被計算》，第一階段是把可播放成片做出來，第二階段才處理學習。

使用者提出「寫成書」的學習方式。討論一開始偏向藉書重做原案，隨後被使用者明確修正：最想知道的是「我們是怎麼用程序寫成影片的」，以及模型更新之後仍成立的底層原理。這項修正優先於先前的引擎操作教程構想。

使用者又指出：「我們往往又被這些專有的英文術語給困難住了」。因此英文障礙不是附錄問題，是每一頁的教學設計問題。最後確認先建立能交給 Codex 的完整寫書交接 ZIP，而不是在聊天框一次寫完書。

## 已確認

| 決策 | 寫作上的落實 |
|---|---|
| 原理而非產品教學 | 主線是畫面、時間、空間、資料、計算、聲音與輸出；工具只作承載例子 |
| 中文先行 | 問題與直觀先出現，正式英文後出現；不得用未知英文解釋未知英文 |
| 英文要能辨認但不必先背 | 正文首次說清楚，章末卡片複習；名稱保留供搜尋及看程式 |
| 理解要可遷移 | 換模型、語言或框架時仍能描述輸入、狀態、規則、輸出與驗收 |
| 原案是案例 | 正確揭露實際技術與未達標部分，不把個案當通用唯一做法 |
| 交接要能獨立接手 | 所有必要背景在檔案裡，不能要求 Codex 讀本聊天才懂 |

## 本交接新增的編輯提案

六部二十四章、約 6.5～9 萬中文字主文、較短的 60～90 秒畢業作品、第一批前言與第 1～3 章、以及第 4 章校準樣章，均為本次整理出的實作方案。不是使用者曾逐項批准的硬性需求。可在不破壞核心目標的前提下微調，須記錄理由。

## 不要承接的錯誤前提

不把口語提及 GPT 或 Claude 新模型、社群影片測試等寫成已查證的發布史或模型排名。模型強弱與程式影片的因果推導不同；漂亮作品不是全面能力證明。主書不必依賴當前模型名稱。

也不沿用「Shader 就等於每個像素」、「所有 Noise 都平滑」、「只要 Seed 相同任何電腦輸出都一樣」、「換旁白一定不用調動畫」等過度簡化，見技術校正表。
