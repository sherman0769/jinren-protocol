# 圖解與動態圖的規格

每張圖只承擔一個主要因果說明。使用中文標題與標籤；英文只在已經理解的名稱旁邊補充，不讓圖比正文更難。採用簡潔留白、清楚線寬、合理字號，黑白打印仍能用線型與標籤區分。

圖解要有四部分：輸入是甚麼、規則做甚麼、輸出看到甚麼、這個例子忽略甚麼。數學圖需標座標軸與單位。時間序列圖須標 0 秒、0.5 秒等真實時點，不能把過程當數據而沒有比例。

靜態圖適合拆機制；要證明速度或連續性時，補可拖曳時間點的演示或短片，同時提供靜態替代圖和文字描述。可讀性不依賴自動播放、網路或顏色。互動功能是輔助，不是看懂正文的前提。

為確保文字和公式正確，技術圖優先用可重建的 SVG／程式繪圖。若另外使用生成式圖像，不能把生成的不精確座標、公式、二維碼當工程證據。圖形生成來源、腳本和參數要保留。
