# 數學與程式的教學規格

## 公式要有四個伴隨資訊

先用中文講計算目的；逐個變量解釋意義與單位；指出適用範圍；帶一次具體數字。例：`t = n / fps` 中 n 是從零起算的影格編號，fps 是每秒影格數，t 是秒。30 fps 的 n=45 得 1.5 秒。

`p = a + (b-a)u` 先說「從起點出發，加上全程的某個比例」。a、b、p 單位都相同，u 是無單位比例。範例先限制 u 在零到一，再交代超出範圍的外插不是本例需求。

`x += v` 只有在 v 的單位已是每步位移時才合理；若 v 是像素／秒，須寫 `x += v * dt`。明確狀態式模擬的初始狀態與取樣步長；不得拿機器每幀耗時作影片時間。

## 程式碼分三級

第一層「中文偽程式」幫助理解，不宣稱可執行。第二層「最小可執行例子」一次只示範一個核心機制。第三層「工程完整版本」放書後配套，不用五百行程式碼把正文壓垮。

每份可執行例子都需記錄：用途、最小依賴、輸入和輸出、命令、預期結果、可改參數、錯誤處理、實際測試環境、未驗證平台。先說明運行目錄，命令里的文件名與實際文件要一致。

正文引用程式檔時，盡可能用函數名或片段標記，不手寫容易過期的行號。修改程式碼後同步更新示例數字、輸出圖與測試。未知命令不要假設能跑；在出版前以乾淨環境重建。

## 只改一個變量

練習先改持續時間，不同時換字體、顏色、粒子數和框架。讓讀者先預測，再執行，再解釋差異。給 AI 的提示應限制不得改變其他條件，並要求回報改哪一個參數。
