# 正文字元統計口徑

本專案以「可見字元」作為中文篇幅預算，避免把英語 word count 混入。主數字包含中文、英文字母、數字、標點，排除空白；同時另報中文字元、字母與數字、標點等數量。

計算只使用一組 `<!-- BODY_START -->` 與 `<!-- BODY_END -->` 之間的內容，移除 Markdown 標記、標題行、程式碼區塊、圖片、網址、引用代號與註腳標記。此口徑較保守，章末金句、來源、附錄、規格、README、Podcast 不計入正文。正文有業務表格時可計可見內容，不能把同一份資料大量重印湊長。

標記不存在、重複或順序錯誤即拒絕統計，不退回整檔字數。章內出現英文不以一整個英文單字算一字；報告應使用完整名稱「正文可見字元」，不要悄悄說成中文純字數。

約 84,000 是本次編輯預算，不是硬性承諾。若後續使用者指定最低字數，需先修訂統計口徑與安全餘量，不能把不同口徑的數字直接比較。

本腳本能防止常見誤算，不能判斷是否為湊字而重複論證。跨章去重、資料表重印與正文完整性需要另外審稿。
