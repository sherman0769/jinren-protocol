# 長文寫作協作｜可由 Codex 當前模型或 Pro 接稿

## 分工不是能力幻想

Codex 是專案執行與內容工程環境；當前已授權模型能完成長文時，可依章規格直接寫作。Pro 可以作為使用者選擇的長文協作者，但不是必需的前置工具。本交接不附跨產品自動控制、API 金鑰或訂閱額度轉接。

只有使用者明確指定外部長文模型寫正式稿時，Codex 才先出寫作包、等待該章稿件；其他研究、案例與測試工作繼續。阻塞限於該任務，不假稱全案不能做。

## 一章寫作包必需內容

章 ID、書名、章名、唯一任務、讀者前後變化、論證順序、與前後章的分工、目標篇幅、核心術語及中文說法、經查核主張與來源定位、不可說的過度結論、固定案例資料與版本、反例、教學驗收，以及段落標記規則。

完整章規格已在 `01_plan/chapters/`，不可再用一般書稿模板沖淡。只附寫作當下需要的相關上下文，不一次灌入全部研究登錄與所有章節。

## 送稿指令範本

「請依本章規格完成正式繁體中文長文。先讓零基礎讀者理解問題，再帶入三個核心術語與必要深度；不要寫成講義條列。案例是虛構，不冒充作者經歷。區分查證事實、作者判斷與假設，不新增無來源數字。保留反例與不適用範圍。正文用 BODY_START／BODY_END 包住，章末金句、來源與待作者確認事項放在外面。請完成這一章，不同時縮寫整本書。」

## 接稿檢查

先以章唯一任務驗收，再查引用是否支持主張；來源代號在索引中存在並不代表主張已被支持。檢查數字與案例、角色與屬性、用詞與同義重複。句子可朗讀但不能因流暢而刪掉重要限制。

通過編輯才標 `EDITED`，再衍生 Podcast。口播改寫不得新增正文未核對的技術結論。正文若後改，依雜湊與版本更新衍生稿。

## 狀態枚舉

`NOT_STARTED` → `RESEARCH_READY` → `DRAFTING` → `DRAFTED` → `EDITING` → `EDITED` → `DERIVED` → `VERIFIED`。

`WAITING_FOR_AUTHORIZED_MANUSCRIPT` 只表示指定外部稿件未到；不是檔案存在就可跳過的任務。章完成數須依實際內容與編輯紀錄計算，不能只改 JSON 欄位。
