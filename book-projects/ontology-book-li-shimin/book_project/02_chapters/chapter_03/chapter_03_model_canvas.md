# 第 3 章小模型｜已填與遷移

依正式稿 1.0.0。中文教學表示，非已測形式語法。

| 類別 | 具體例 | 本例描述 |
|---|---|---|
| 人 | P001 | 姓名林沐安，與 P003 不同人 |
| 課程 | C101 | AI 基礎應用 |
| 班別 | S101 | 容量 3，開設 C101，授課者 P010 |
| 報名 | E001 | 報名人 P001，班別 S101，已確認 |
| 付款 | PAY001 | 對 E001，3,000 新台幣，已結清 |

E005 也是 P001 對 S101 的報名，狀態取消；與 E001 的先後未提供。不要合併成單一不明狀態線，也不要補寫事件故事。

自畫模型後朗讀每條線，再填：能各自改變的對象＿＿；值與對象的分界＿＿；同名處理＿＿；反向查詢如何理解＿＿；仍缺少的時間資料＿＿。此紙上作品不提供退款權限。
