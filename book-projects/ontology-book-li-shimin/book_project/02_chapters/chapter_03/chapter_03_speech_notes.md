# 第 3 章演講筆記｜先找可以各自改變的對象

來源正式章稿 1.0.0；SHA 見 EP03 derivation.json。約十分鐘設計，實際時長未測。

前兩分鐘：口述學員「想換課程時間」，讓聽眾分辨整門課、某一班與自己的報名。說明一班改期不必改另一班，人取消報名不會刪掉課程。

接續兩分鐘：以班別／S101 說明哪一種與哪一個，再用容量三與授課者 P010 分開值和對象。兩位林沐安明確不同，禁止姓名去重。

中段三分鐘：逐條口述報名到人、報名到班、班到課、付款到報名。把「有關」改成具體動詞；示範錯把授課關係讀成類別包含會產生什麼荒謬句子。

再兩分鐘：同一人同一班的 E001 已確認、E005 已取消，需要分辨紀錄；不補寫先後。付款 PAY001 對應 E001。允許其他存法，只檢查是否保留所需識別與查詢能力。

結尾一分鐘：周言青是外部講師而非員工；講師兼學員是另設假例，不寫回固定資料。請聽眾用五對象模型回答取消為何不刪人。

追問處理：教室現在作字串可夠用；需要設備與排程時才考慮獨立對象。報名對象不是完整事件日誌；模型沒有提供授權執行。
