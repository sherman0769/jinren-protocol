# 第 2 章簡報文字大綱

來源正式章稿 1.0.0；八頁文字規劃，未生成 PPTX。

1. **「取消課程」到底取消誰？** 同一要求對照課程、班別與一次報名；先保留歧義。
2. **先定範圍。** 眼前處理報名與名額；未納入不代表不存在。
3. **再定看法。** 一門課可開兩班，人透過報名連到某班；這是為用途作的概念化。
4. **本體讓重要約定明確。** 詞義、關係、使用條件；圖與檔案格式不是完成證明。
5. **一個詞的三種語境。** 哲學／知識工程／特定平台；各自問題與來源不同。
6. **四種責任。** 推論／資料驗證／業務政策／執行授權；整合不消除差別。
7. **一張定義卡。** 名稱、意思、範圍、例子、反例、負責角色；用已確認報名示範。
8. **讓另一個人來用。** 付款未知仍占位嗎？可判退款資格嗎？以答案檢查定義卡。
