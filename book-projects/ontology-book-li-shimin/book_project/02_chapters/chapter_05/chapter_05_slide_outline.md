# 第 5 章簡報文字｜八頁

由正式章稿 1.0.0 衍生；版本與 SHA 見 EP05 derivation.json。本檔是頁面文字，尚無 PPTX 或圖片。

1. **哪一天才算懂公司？** 願望「什麼都能問」缺少完成條件。講者引導聽眾提出一個具體決策。
2. **需求卡的四格** 問題／可接受答案／依據／例外。示例：指定班別名額，而非模糊課名。
3. **三個相依問題** C101 開 S101、S102；S101 佔位為 E001、E002；容量 3 減 2 等於快照剩 1。不要只展示結果數字。
4. **兩題測出邊界** 候補 E003→P003，不能混同名 P001；E002 付款未知，不能判未付。
5. **誰能確認哪件事** 流程經驗、資料讀取、政策決定分開；同名狀態可能描述不同階段。
6. **納入與排除都有理由** 納入教務查詢；排除預測、薪資、健康資料與直接退款。資料不足不是偷偷改需求的理由。
7. **三種驗收** 模型表達／資料品質／操作授權；任何一項通過不能代替另外兩項。
8. **帶走一張需求卡** 寫一題、答對例、未知例、不能執行的動作，讓另一人找一個反例。
