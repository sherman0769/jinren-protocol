# 第 12 章｜轉班行動契約練習

依正式稿 1.0.1。此表是設計練習，不是核准單、真實請求或測試成功紀錄。起點為固定 SNAP-001，演練 E001／P001 從 S101 轉至 S102；POL-001 沒有定義完整轉班規則，先補政策，不逕行執行。

| 責任 | 已知示例與待填內容 |
|---|---|
| 查 | E001 與 P001；查原班狀態、目標當下容量、未完成申請。資格／價差／期限規則：待填。 |
| 議 | 保留歷史並列出將改哪些紀錄；提案 ID／版本：待填。款項與通知是否另案：待填。 |
| 核 | 演練由課務管理者判定；可信身分來源、核准參數、有效期及撤回方式：待填。 |
| 做 | 真正執行服務／角色：待填；AI 仍只能提案。提交時強制檢查：待填。 |
| 併行 | 如何避免核准後目標席位被取走仍誤報成功：待填。跨服務時不假定單一交易。 |
| 重試 | 原操作 ID 的保存與參數綁定：待填；逾時先查原結果，不能直接新建一筆。 |
| 部分成功 | 報名、款項、通知分別記結果；何人接手、補償的權限與限制：待填。 |
| 驗 | 讀回兩班／報名狀態及操作結果；成功記錄如何對到本案：待填。 |

測試設計：無核准、核准後改參數、重複提交、逾時、目標滿額、通知失敗。逐項填輸入／應拒絕或成功條件／實際結果／證據位置。**全部尚未執行**，不能填「通過」或當成服務已上線。
