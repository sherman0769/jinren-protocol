# EP02 節目附註

- 唯一任務：分辨本體的知識工程用途、哲學語境與平台定義，完成可被反例檢查的中文定義卡。
- 三個錨點：領域是選定範圍；概念化是為目的選擇對象與關係；本體是將重要約定明確表達的規格。
- 依據：R01 §1–2、R02 §1–3／Step 1、R04 OWL Primer §2–3／§4.1–4.2、R05 SHACL 責任邊界、R14 Fabric overview、R16 Palantir Why create an Ontology。書面連結與版本見第 2 章，查閱 2026-09-28。
- 產品段落只轉述指定公開文件；沒有租戶、推理引擎或企業成效實測。
- 案例仍為 SNAP-001／POL-001；候補政策改變是假設，未改固定案例。定義卡維護角色沒有被當成真人已任命。
- 時長待實際錄音／生成測量，字元與語音驗收狀態見 derivation.json。
