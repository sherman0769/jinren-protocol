# EP04 節目附註

- 唯一任務：按存放／分類／定義／連結／計算診斷缺口，保留既有有效方案，不用新舊排行榜代替選擇。
- 三個錨點：資料綱要安排欄位與條件；知識圖譜以有意義的對象關係組織知識；分析語意層讓指定計算口徑被重用。RDF／SKOS 只提供必要中文責任解釋。
- 依據 R03 RDF Primer §3.1–3.3／§4、R06 SKOS §1.3／3.5.1／5.1、R08 v6 §2.1／3–3.2、R04 §2–3、R26 導言／Get started。日期與連結見第 4 章來源附註。
- 付款兩人與 S101 一人只代表 SNAP-001 已知證據，不是完整企業總數。兩筆付款的報名人 P001／P003 同名不同人。分次付款和教材分類是另外假設。
- 未跑資料庫效能或產品實驗，不聲稱哪個工具一定省錢。語速、時長與實際聽覺理解待聲音驗收。

## 書面來源入口

- R03：[RDF 1.1 Primer](https://www.w3.org/TR/2014/NOTE-rdf11-primer-20140624/)，2014-06-24 Working Group Note，§3.1–3.3、§4。英文全名 Resource Description Framework。本文只借三部分陳述解釋資料模型，不是語法教材，也未宣稱 RDF 是所有圖譜必需的格式。
- R06：[SKOS Reference](https://www.w3.org/TR/skos-reference/)，2009-08-18，§1.3、3.5.1、5.1。英文全名 Simple Knowledge Organization System。分類和形式本體可配合，不能無條件等同；SKOS 本身有形式資料模型，不代表所有分類連接都是領域類別公理。
- R08：[Hogan 等，Knowledge Graphs](https://arxiv.org/html/2003.02320v6)，2021 v6，§2.1、§3–3.2。採入門工作理解，不宣稱唯一通用定義；沒有比較任何資料庫的效能。
- R04：[OWL 2 Primer 第二版](https://www.w3.org/TR/2012/REC-owl2-primer-20121211/)，2012-12-11，§2–3。本體可以有個體陳述，概念與資料非硬性二分。
- R26：[dbt Semantic Layer](https://docs.getdbt.com/docs/use-dbt-semantic-layer/dbt-sl)，導言及 Get started；查閱 2026-09-28，現頁更新標籤 2026-08-18，不是平台統一版本號。只作集中指標的產品例；未實測或引用安全／成本成效。
- 所有付款演算限於 SNAP-001：按 P001／P003 算不同人，不以姓名去重；付款資料不完整，觀察到的證據數不等於現實總數。分類、拆款等情境是另外標示的假設。
